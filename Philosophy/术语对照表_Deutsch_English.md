## 一、德语术语阅读辅助

| 规则 | 说明 | 例 |
|------|------|-----|
| 名词首字母大写 | 德文句中的大写词几乎都是术语，可直接提取 | *der Verstand*, *die Anschauung* |
| 名词化后缀 | `-heit/-keit`、`-ung` 是抽象名词的标记 | Idealität（观念性）、Anschauung（直观）、Vorstellung（表象） |
| 复合词拆分 | 一般「后词是中心，前词是修饰」 | Erkenntnis+vermögen（认识「能力」）、Verstandes+begriff（知性「概念」）、Anschauungs+form（直观「形式」） |
| 属格连接音 -s- | `Verstandes-`、`Gegenstands-` 中的 s 只是属格 | Verstandesbegriff = Begriff des Verstandes |
| 关键复合词 | 直接背诵可省大量查词时间 | Selbstbewusstsein（自我意识）、Sinnenwelt（感性世界）、Verstandeswelt（知性世界）、Gegenstand（对象 = gegen+Stand）、Wahrnehmung（知觉 = wahr+nehmen） |

## 五、常见误译与陷阱

| 陷阱 | 说明 |
|------|------|
| transzendental vs transzendent | 中文旧译常都作「先验」，但康德严格区分：前者在经验界限**内**，后者**越出**界限（参见 [[Kant_Epistemology]]） |
| **Idee** | 一词三义：Kant = 理性理念；Hegel = 绝对理念；Frege/Husserl 语境 = 观念。翻译与检索时必须看作者 |
| Realität / Wirklichkeit / Realismus | 三词三义：实在性（质范畴）、现实性（模态范畴）、实在论（立场） |
| Vorstellung vs Gedanke | Frege 的 Vorstellung 是**主观**的（表象/观念），Gedanke 是**客观**的（思想）——不可混译 |
| Evidenz | 不是「证据」（Beweis/Beleg），是「明证性/自明性」 |
| Geltung | 不是「价值」（Wert），是「效力/有效性」 |
| Anschauung | 译「直观」，不译「直觉」（Intuition） |
| Gesetz | Frege 强调的双义：「是什么」vs「应当是什么」；同时兼有「法律」义 |
| Grundsatz vs Grundgesetz | 前者是「原理」（Kant 的知性原理），后者是「基本法则」 |
| Ding an sich vs Noumenon | 前者是显象的根据，后者是「智思物」；积极义的本体只是悬拟概念 |
| Johann Eduard Erdmann vs Benno Erdmann | 同名不同人（见人物表），是心理主义史最常见的混淆 |
| 「先验主体」≠「我的心灵」 | 混淆二者正是心理主义的起点 |
