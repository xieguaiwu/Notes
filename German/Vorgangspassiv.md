# 德语过程被动语态 (Vorgangspassiv)

## 一、基本概念

过程被动语态（Vorgangspassiv）表示**动作正在进行或被完成**，强调动作本身，而非动作的执行者。相当于中文的"被……"。

---

## 二、构成

### 基本结构

```
werden（变位）+ 第二分词
```

**核心规则**：五大时态变化全部体现在 **werden** 上，第二分词（P.II）始终在句末。

| 时态 | 结构 | 示例 |
|------|------|------|
| 现在时 | werden + Partizip II | Das Buch wird gelesen. |
| 过去时 | wurden + Partizip II | Das Buch wurde gelesen. |
| 完成时 | sind + Partizip II + worden | Das Buch ist gelesen worden. |
| 过去完成时 | waren + Partizip II + worden | Das Buch war gelesen worden. |
| 将来时 | werden + Partizip II + werden | Das Buch wird gelesen werden. |

**时态变化表**（以 machen → gemacht 为例）：

| 时态 | 结构公式 | 例句 |
|------|---------|------|
| 现在时 Präsens | werden（现在时）+ P.II | Die Hausaufgaben werden gemacht. 作业被做了。（正在被做）|
| 过去时 Präteritum | wurden（过去时）+ P.II | Die Hausaufgaben wurden gemacht. 作业被做了。（过去发生）|
| 现在完成时 Perfekt | sein + P.II + **worden** | Die Hausaufgaben sind gemacht worden. 作业已经被做了。|
| 过去完成时 Plusquamperfekt | waren + P.II + worden | Die Hausaufgaben waren gemacht worden. 作业（在过去某时之前）已经被做了。|
| 将来时 Futur I | werden + P.II + werden | Die Hausaufgaben werden gemacht werden. 作业将被做。|

> ⚠️ **易错点**：被动现在完成时用的是 **worden**（werden 的第二分词），**不是 geworden**！geworden 是主动态中 werden 的第二分词（如：Er ist Lehrer geworden. 他成为了老师）。

---

## 三、各时态详解

### 1. 现在时（Präsens）

```german
Das Haus wird gebaut.
房子正在被建造。

Die Arbeit wird erledigt.
工作正在被完成。
```

**变位表**：

| 人称 | 形式 |
|------|------|
| ich | werde gefragt |
| du | wirst gefragt |
| er/sie/es | wird gefragt |
| wir | werden gefragt |
| ihr | werdet gefragt |
| sie/Sie | werden gefragt |

### 2. 过去时（Präteritum）

```german
Das Haus wurde 1990 gebaut.
这栋房子建于1990年。

Der Brief wurde gestern abgeschickt.
信件昨天被寄出。
```

**变位表**：

| 人称 | 形式 |
|------|------|
| ich | wurde gefragt |
| du | wurdest gefragt |
| er/sie/es | wurde gefragt |
| wir | wurden gefragt |
| ihr | wurdet gefragt |
| sie/Sie | wurden gefragt |

### 3. 完成时（Perfekt）

**结构**：sein（变位）+ 第二分词 + worden

```german
Das Haus ist gebaut worden.
房子已经被建好了。

Der Auftrag ist erledigt worden.
任务已经完成了。
```

**注意**：被动语态的完成时用 **sein** 而非 haben。

**变位表**：

| 人称 | 形式 |
|------|------|
| ich | bin gefragt worden |
| du | bist gefragt worden |
| er/sie/es | ist gefragt worden |
| wir | sind gefragt worden |
| ihr | seid gefragt worden |
| sie/Sie | sind gefragt worden |

### 4. 过去完成时（Plusquamperfekt）

```german
Das Haus war schon gebaut worden, als wir kamen.
当我们来的时候，房子已经被建好了。
```

### 5. 将来时（Futur I）

```german
Das Haus wird gebaut werden.
房子将被建造。
```

### 6. 将来完成时（Futur II）

```german
Das Haus wird gebaut worden sein.
房子将已经建好。
```

## 四、主动句转被动句

### 基本转换规则

| 主动句成分 | 被动句成分 |
|------------|------------|
| 第四格宾语 | 第一格主语 |
| 第一格主语（施事者） | von + 第三格（可省略） |
| 动词 | werden + 第二分词 |

**示例**：

| 主动句 | 被动句 |
|--------|--------|
| Der Arzt operiert den Patienten. | Der Patient wird vom Arzt operiert. |
| 医生给病人做手术。 | 病人被医生做手术。 |
| Jemand stahl das Fahrrad. | Das Fahrrad wurde gestohlen. |
| 有人偷了自行车。 | 自行车被偷了。 |

### 施事者的表达

需要说明施动者时：**人 / 机构** 用 **von + D**，**事物 / 手段** 用 **durch + A**。

#### von + Dativ（第三格）

适用场景：强调有**主观能动性的直接施动者** → 人、机构、组织。

```german
Der Brief wird von meinem Vater geschrieben.
这封信是由我的父亲写的。

Der Brief wurde vom Chef unterschrieben.
信件被老板签署了。

Das Bild wurde von einem berühmten Maler gemalt.
这幅画是由一位著名画家画的。
```

💡 施动者是"人"——用 von。

#### durch + Akkusativ（第四格）

适用场景：强调动作的**方式、媒介或间接原因** → 工具、手段、事件、媒介。

```german
Die Stadt wurde durch ein Erdbeben zerstört.
这座城市被一场地震摧毁了。

Die Nachricht wurde durch das Radio verbreitet.
消息通过广播传播。
```

💡 施动者是"原因/手段"——用 durch。

> 💡 **小提示**：在被动句中，von/durch 短语可以**直接省略**，这正是被动态的常见用法。

## 五、不及物动词的被动语态（无人称被动态 Unpersönliches Passiv）

不及物动词（无第四格宾语的动词）也能构成被动语态，称为**无人称被动语态**——不及物动词也能变被动！

**① 基本结构**：

```
Es + werden + P.II + 其他成分
```

**特点**：
- 无第一格主语
- 用代词 **es** 作占位主语
- 强调动作本身

**② es 的省略规则**：

当其他成分（如状语、第三格）移到句首时，**es 必须省略**，动词仍保持第二位。

⚠️ 只有句首无其他成分时才保留 es。

**③ 适用动词类型**：表示"行为动作"的不及物动词，如：

| 动词 | 含义 |
|------|------|
| arbeiten | 工作 |
| tanzen | 跳舞 |
| lachen | 笑 |
| helfen | 帮助 |
| sprechen | 说话 |

**例句展示：主动 → 被动转换**：

```german
Man arbeitet am Sonntag.
人们在周日工作。

→ Es wird am Sonntag gearbeitet.
   被动语态（保留 es，句首无其他成分）：周日人们工作。

→ Am Sonntag wird gearbeitet.
   被动语态（省略 es，状语在句首——最常用的表达方式）：周日（有人）工作。
```

其他例句：

```german
Es wird hier nicht geraucht.
这里禁止吸烟。

Ihm wurde geholfen.
他得到了帮助。

Es wurde viel gelacht.
大家笑得很开心。

Nachts wird nicht gearbeitet.
晚上不工作。
```

**注意**：如果句首有其他成分，es 省略：

```german
Hier wird nicht geraucht.
这里禁止吸烟。
```

> 🧠 **记忆口诀**：句首有词 es 消失，句首无词 es 来顶。

## 六、绝对不能变被动的动词（B1 考点）

以下五类动词**绝不能构成被动态**，是选择题和改错题的必考点——直接使用主动态即可。

### 1. 拥有类动词

| 动词 | 含义 |
|------|------|
| haben | 有、拥有 |
| besitzen | 占有、具有 |
| bekommen / erhalten | 收到、得到 |

表"占有/获得"关系，无被动。

### 2. 度量类动词

| 动词 | 含义 |
|------|------|
| wiegen | 重量为 |
| kosten | 价值、花费 |
| enthalten | 包含、含有 |

表数量/度量/包含关系。

### 3. 反身动词

| 动词 | 含义 |
|------|------|
| sich waschen | 洗澡 |
| sich freuen | 高兴 |
| sich erholen | 休息、恢复 |

主语与宾语为同一人（详见 [[Reflexive Verb]]）。

### 4. 状态/运动类动词

| 动词 | 含义 |
|------|------|
| gehen | 走、去 |
| kommen | 来 |
| bleiben | 停留、保持 |
| wohnen / sein | 居住 / 是 |

### 5. 感官状态类动词

| 动词 | 含义 |
|------|------|
| sehen | 看见 |
| hören | 听见 |
| schmecken | 尝起来 |
| kennen / wissen | 认识 / 知道 |

> 🧠 **记忆口诀**：**拥有度量不能变**——这五类动词直接使用主动态即可。

## 七、情态动词与被动语态

### 结构

```
情态动词（变位）+ 第二分词 + werden
```

| 时态 | 结构 | 示例 |
|------|------|------|
| 现在时 | muss + gelesen + werden | Das Buch muss gelesen werden. |
| 过去时 | musste + gelesen + werden | Das Buch musste gelesen werden. |
| 完成时 | hat + gelesen + werden + müssen | Das Buch hat gelesen werden müssen. |

### 常见用法

```german
Das Problem muss gelöst werden.
这个问题必须被解决。

Die Arbeit kann heute erledigt werden.
这项工作今天可以完成。

Der Brief sollte gestern abgeschickt werden.
这封信本应该昨天寄出。

Das Fenster darf nicht geöffnet werden.
这扇窗户不许打开。
```

---

## 八、带 zu 的被动不定式

### 结构

```
zu + 第二分词 + werden
```

常与 *sein* 连用，表示"能够被……"：

```german
Das Problem ist zu lösen.
= Das Problem kann gelöst werden.
这个问题可以被解决。

Die Arbeit ist schnell zu erledigen.
= Die Arbeit kann schnell erledigt werden.
这项工作可以很快完成。

Das Buch ist nicht zu verstehen.
= Das Buch kann nicht verstanden werden.
这本书无法被理解。
```

## 九、被动语态的替代形式

德语中常用其他结构代替被动语态，使表达更自然。

### 1. sich lassen + 不定式

```german
Das Problem lässt sich leicht lösen.
= Das Problem kann leicht gelöst werden.
这个问题容易解决。

Das Fenster lässt sich nicht öffnen.
= Das Fenster kann nicht geöffnet werden.
这扇窗户打不开。
```

### 2. sein + zu + 不定式

```german
Die Aufgabe ist schwer zu erfüllen.
= Die Aufgabe kann schwer erfüllt werden.
这项任务难以完成。

Es ist viel zu tun.
= Es kann viel getan werden.
有很多事要做。
```

### 3. man + 主动语态

```german
Man spricht hier Deutsch.
= Hier wird Deutsch gesprochen.
这里说德语。

Man verkauft hier keine Zigaretten.
= Hier werden keine Zigaretten verkauft.
这里不卖香烟。
```

### 4. funktionieren 等动词

某些动词本身含有被动意义：

```german
Die Tür öffnet sich automatisch.
门自动打开。

Das Buch verkauft sich gut.
这本书卖得很好。
```

## 十、Vorgangspassiv 与 Zustandspassiv 对比

| 特征 | Vorgangspassiv（过程被动） | Zustandspassiv（状态被动） |
|------|---------------------------|---------------------------|
| 助动词 | werden | sein |
| 强调 | 动作过程 | 动作结果/状态 |
| 中文翻译 | 被…… | ……着/已…… |
| 示例 | Die Tür wird geöffnet. | Die Tür ist geöffnet. |
| 含义 | 门正在被打开 | 门开着 |

**更多对比**：

| 过程被动 | 状态被动 |
|----------|----------|
| Das Fenster wird geschlossen. | Das Fenster ist geschlossen. |
| 窗户正在被关上。 | 窗户关着。 |
| Der Kuchen wird gebacken. | Der Kuchen ist gebacken. |
| 蛋糕正在被烘烤。 | 蛋糕烤好了。 |

## 十一、常见错误

### 1. 混淆 werden 和 sein

❌ *Das Haus wird gebaut.*（状态）
✅ Das Haus **ist** gebaut.（状态：房子已建好）
✅ Das Haus **wird** gebaut.（过程：房子正在被建）

### 2. 完成时用错助动词

❌ *Das Haus hat gebaut worden.*
✅ Das Haus **ist** gebaut worden.

### 3. 情态动词被动语态词序错误

❌ *Das Buch wird gelesen müssen.*
✅ Das Buch **muss gelesen werden**.

### 4. 无人称被动省略 es 时机错误

✅ *Es wird hier nicht geraucht.*（es 在句首占位，正确）
❌ *Hier wird es nicht geraucht.*（句首已有成分，es 应省略）
✅ Hier **wird** nicht geraucht.

### 5. 被动完成时误用 geworden

❌ *Das Haus ist gebaut geworden.*
✅ Das Haus **ist gebaut worden**.

被动现在完成时用 **worden**（werden 的第二分词）；**geworden** 只用于主动态（Er ist Lehrer geworden.）。

## 十二、实用例句

```german
1. Die Schweine werden an den Metzger verkauft.
   猪被卖给屠夫。

2. Das Gesetz wurde vom Parlament verabschiedet.
   法律由议会通过。

3. Ihm wurde mit einer Gehaltserhöhung gedroht.
   他被威胁要降薪。

4. Es wird darum gebeten, nicht zu rauchen.
   请勿吸烟。

5. Der Antrag muss bis Freitag eingereicht werden.
   申请必须周五前提交。

6. Das Problem ist nicht zu ignorieren.
   这个问题不容忽视。

7. Die Tür lässt sich nicht öffnen.
   门打不开。

8. Man sagt, er sei reich.
   据说他很富有。（被动含义的主动表达）
```

## 十三、记忆技巧

1. **核心口诀**：werden + 第二分词 = 过程被动
2. **时态记忆**：现在用 *wird*，过去用 *wurde*，完成用 *ist...worden*（被动用 worden，不用 geworden）
3. **情态动词**：情态动词 + 分词 + werden（情态词在两头）
4. **无人称被动**：不及物动词也能被动，es 开头来占位；句首有词 es 消失，句首无词 es 来顶
5. **替代形式**：*sich lassen* 和 *sein...zu* 让表达更地道
6. **施动者**：人/机构 von + D，事物/手段 durch + A
7. **不能被动**：拥有、度量、反身、状态运动、感官状态——五类动词直接用主动态
