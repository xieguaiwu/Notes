# Body Reading - Applied Case Classroom

> [!abstract] 概述
> 一个完整解码示范：课堂上，坐在「认识自己但自己不认识对方」的高年级女生身边，其行为组合为：前倾偏头看黑板、全程零目光、右臂支撑头部并向观察者侧遮挡、伸展时仍保持交叉。
> 本笔记演示部位信号的组合流程，规则见 [[Body Reading - Core Principles]]。

## 1. 信号逐项解码

| 观察 | 逐项解读 | 权重 | 依据笔记 |
|---|---|---|---|
| 前倾偏头看黑板 | 任务注意，非人际信号。前倾对象是黑板，不是邻座 | 低 | Torso §1 警告框 |
| 全程零目光 | 支持不趋近；但课堂规范 + 「对方认识自己」的不对称 + 客体化警觉三重混淆 | 中 | Head §4 |
| 右臂支撑 + 方向性遮挡 | 屏障行为。方向对着观察者 → 不是随机舒适位。撑头本身是疲劳通用动作 | 中高 | Arms §3 |
| 伸展仍交叉 | 释放瞬间维持闭合 → 持续自我管制，非瞬时习惯。全程最强证据 | 高 | Torso §4 诊断窗口 |

## 2. 组合判断

信号组合 = 零趋近 + 轻度方向性屏障 + 持续性收拢。

排除项：
1. 非敌意。敌意的标志（转身背离、对峙朝向、叉腰）全部缺席；她的朝向对象是合法第三目标。
2. 非好感。无任何趋近信号：无瞥视、无朝向、无自我呈现整理动作。

留存假设（按支持度排序）：
1. 对陌生异性的防御性自保。身体暴露 + 被注视感 → 自我监控 → 屏障。与「认识但陌生」完全兼容。
2. 规范性不互动。课堂对陌生邻座的默认配置，四项观察均有无害版本。
3. 知情者的保留。她认识观察者，回避可能是既有印象驱动的选择。姿态文献无法排除。

> [!important] 结论模板
> 证据支持的最保守读法：「维持一条明确、刻意、非敌意的界限，不开放互动」。
> 三假设均未淘汰。姿态只能定位界限存在，不能定位界限成因。

## 3. 可检验的区分预测

| 检验 | 若成立 | 指向 |
|---|---|---|
| 课间铃声后屏障是否解除 | 解除 → 纯课堂行为 | 假设 2 |
| 对另一侧邻座（尤其女生）是否同样遮挡交叉 | 是 → 特质习惯 | 假设 2 |
| 观察者有动作时她有无微反应（余光、姿态微调） | 有但持续回避 → 印象管理 | 假设 1 或 3 |
| 完全无反应 | 低卷入 | 假设 2 加权 |

## 4. 本案例的方法学教训

1. **语境翻转**：坐姿收臂读作紧张/拘礼。若误用站姿规则会读成「放松」。
2. **对象绑定**：前倾、朝向、目光都必须先绑定方向对象。任务朝向不是人际朝向。
3. **不对称信息**：「对方认识我而我不认识她」使全部信号多一层知情解释，概率判断需打折。
4. **单次观察无诊断力**：需要课间对照、方向对照、反应性对照三类复测。
