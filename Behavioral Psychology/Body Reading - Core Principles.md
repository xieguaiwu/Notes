# Body Reading - Core Principles

> [!abstract] 概述
> 解读身体姿态前必须掌握的 6 条原则。来源以 Mehrabian (1969) 姿态综述为主。
> 所有部位速查笔记（[[Body Reading - Head and Gaze]] 等）都建立在这几条上。

## 1. 编码与解码

同一姿态有两个方向：

| 方向 | 含义 | 例子 |
|---|---|---|
| 编码 | 传达者做出姿态时，姿态实际对应的心理状态 | 讨厌对方的人坐得更远 |
| 解码 | 观察者看到姿态时，推断出的心理状态 | 观察者把远距离读成讨厌 |

编码与解码结果一致 → 该信号可靠。两者不一致 → 信号误导，慎用。

## 2. 态度信号与地位信号是两套系统

每个姿态变量可能同时携带两类信息：

| 变量 | 主要携带 | 备注 |
|---|---|---|
| 距离 | 态度 | 越近越积极；地位差距越大越远 |
| 目光接触 | 态度 + 地位 | 见曲线关系 |
| 身体朝向 | 站姿=地位，坐姿=态度 | 见 [[Body Reading - Torso and Orientation]] |
| 叉腰（仅站姿） | 态度 + 地位 | 消极态度 + 对方低地位 |
| 手臂开放度 | 女性编码者与地位相关 | 站/坐方向相反 |

## 3. 曲线关系：更多不等于更积极

> [!important] 三条曲线
> 1. 目光：厌恶对象最少，中性对象最大，极喜好对象略降（亲近补偿）。
> 2. 放松-态度：对厌恶对象放松极高或极低，对喜好对象取中等。
> 3. 放松-地位：低地位对象前最放松，高地位对象前中等放松。

直线外推会错。看到「零目光接触」，先考虑抛物线负端与补偿效应两种可能。

## 4. 即时性与规范

即时性 = 距离、朝向、目光、接触合成的「趋近程度」。规范内即时 → 积极态度。超出规范 → 被推断为消极。解读时先问：这个行为的即时性水平在本情境的规范区间内吗？

## 5. 姿态还有调节功能，不都是态度

姿态变化可以表示：提出新论点、暂时退出互动、管理话轮。它们与好恶无关。听讲时看黑板、思考时移开目光都属于此类。

## 6. 实操流程：4 步过滤

1. **建基线**：先观察此人的常态姿态。无基线不解读。
2. **定情境**：识别任务约束（课堂、排队、电梯）。约束内的默认动作不计入人际信号。
3. **查方向与持续性**：屏障朝向谁？释放时刻（伸展、起身）是否仍维持闭合？方向特异 + 持续 → 权重高。
4. **要求组合**：单信号不下结论。屏障 + 零目光 + 无趋近才构成一个组合证据。

> [!tip] 三问快速筛
> - 换个对象（另一侧邻座），此行为还在吗？
> - 换个时刻（放松瞬间），此行为还维持吗？
> - 有没有更省力的非人际解释（疲劳、桌椅位置）？
> 三答都否 → 信号指向人际态度。

## 注意事项

1. 源研究是 1960-70 年代实验室编码/解码研究，样本小，相关非因果。
2. 个体习惯差异（有人常年交叉手臂）只能靠基线排除。
3. 本库所有解读都是概率判断，不是证明。
