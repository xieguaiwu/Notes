# Body Reading - Head and Gaze

> [!abstract] 概述
> 目光接触量与头部姿态的直接解读。来源：Mehrabian (1969)、James (1932)、Dael et al.。
> James (1932)：四类姿态（接近/退缩/扩展/收缩）中，头部与躯干是最重要的指标部位。

## 1. 目光接触量 → 态度（抛物线，非线性）

| 观察到的目光量 | 直接解读 | 依据 |
|---|---|---|
| 最少 | 厌恶端；或话题令人尴尬 | Mehrabian 1968b；Exline 等 |
| 接近最大 | 中性或温和积极 | Mehrabian 1968b |
| 高但略降 | 极喜好（亲近度高时目光做补偿性减少） | Argyle & Dean 1965 |

> [!important] 抛物线的两端
> 零目光接触 = 曲线负端 = 厌恶或不自在。但曲线正端的极喜好也会轻微减少目光。区分两者靠其余信号：后者伴随趋近姿态（朝向、距离近）。

## 2. 目光与地位

- 中高地位对象 → 目光最多；低地位对象 → 最少；极高地位 → 回落至中等。
- 站立时男女都对高地位对象有更多目光。
- 地位效应与态度效应相互独立。

## 3. 敌意情境的反转

威胁性的人引出更多警觉与更多目光接触。在敌意对话中，目光接触越多 → 越令人不快。因此「多目光 = 积极」只在无威胁情境成立。

## 4. 零目光接触的三种成因（不可直接读作厌恶）

| 成因 | 伴随信号 | 判别法 |
|---|---|---|
| 厌恶/排斥 | 转身背离、最不直接朝向、无趋近 | 看朝向 |
| 害羞/社交警惕 | 收臂、自我触碰、身体受限 | 看手臂与放松度 |
| 情境规范（无互动义务） | 全场默认行为一致 | 换情境复测 |

> [!tip] 实操判别
> 先确认该情境是否存在互动义务。课堂听讲、排队时，邻座互不直视是默认行为，不构成态度证据。义务存在而仍零目光 → 才有解读价值。

## 5. 头部姿态 → 情绪

| 头部姿态 | 直接解读 | 来源 |
|---|---|---|
| 头部正直、朝向对方 | 愉悦 | Dael 聚类 11 |
| 头部上仰 + 侧偏 | 愉快/兴奋 | Dael 聚类 9 |
| 上视目光 + 躯干后倾/后移 | 焦虑 | Dael 聚类 3 |
| 低头 + 垂肩 + 躯干前倾 | 抑郁、沮丧、颓丧（收缩） | James 1932 |
| 头竖直 + 抬肩 + 挺胸 | 骄傲、自负、轻蔑（扩展） | James 1932 |
| 重复性头部动作 + 触摸自己 | 低唤醒/被动情绪，无情绪特异性 | Dael 聚类 5/7 |
| 头转向侧面（静态） | 回避朝向的一部分；需结合肩部朝向读 | Dael 因子 3 |

## 6. 头 vs 肩的优先级

头部、肩部、腿部朝向高度相关（r > 0.80）。头部最易主动控制 → 伪装成本最低。肩部朝向更难伪装 → 肩与头不一致时，信肩。
