# Body Reading - Torso and Orientation

> [!abstract] 概述
> 躯干倾斜、侧倾、身体朝向、体积变化的直接解读。
> 身体朝向是四类姿态中最难伪装的部位之一；James (1932)：头与躯干位置是姿态四分类的最重要指标。

## 1. 躯干前倾 vs 后仰（就座时）

| 观察 | 直接解读 | 来源 |
|---|---|---|
| 前倾（斜躺角小） | 态度积极；躯干放松度低 | Mehrabian 1968a |
| 后仰远离 | 消极态度被推断 | Mehrabian 1968a |
| 后仰 + 上视 | 焦虑 | Dael 聚类 3 |
| 斜躺度大且稳定 | 放松信号；对低地位对象更多 | Mehrabian & Friar 1969 |

> [!warning] 前倾的两种含义
> 「前倾 = 积极」仅指朝交流对象前倾。朝黑板、屏幕、文件前倾是任务注意，不是人际信号。先确认前倾的方向对象。

## 2. 侧倾（就座时）

| 观察 | 直接解读 |
|---|---|
| 中等侧倾 | 积极态度 |
| 极大或极小侧倾 | 中性或消极 |

侧倾是放松指标。放松与态度是曲线关系：厌恶对象引出极高或极低的放松，喜好对象对应中等放松。

## 3. 身体朝向（肩部朝向为代表）

肩部朝向 = 垂直于肩平面的平面偏离对方正中矢状面的角度。

| 姿态语境 | 朝向直接解读 | 来源 |
|---|---|---|
| 坐姿 + 女编码者 | 抛物线：最厌恶 → 最不直接；中性 → 最直接；极喜好 → 中等 | Mehrabian 1968b |
| 坐姿 + 男编码者 | 仅对极喜好对象朝向较不直接（并肩倾向） | Mehrabian 1968b |
| 站姿 | 与态度无关；对高地位对象更直接 | Mehrabian 1968a |

朝向与目光是独立指标，可分别读。

## 4. 体积变化（扩展/收缩）

| 观察 | 直接解读 | 来源 |
|---|---|---|
| 挺胸 + 躯干直立/后仰 + 抬肩 | 骄傲、自负、支配（扩展类） | James 1932 |
| 胸部塌陷 + 垂肩 + 前倾低头 | 抑郁、沮丧（收缩类） | James 1932 |
| 占空间 + 四肢开放 | 权力、支配信号 | PowerPosing |
| 占空间 + 四肢收拢（立正） | 顺从、遵从规范、拉远社会距离 | SizeOrOpenness |
| 伸展 + 释放动作 | 放松释放的瞬间 | — |

> [!important] 释放时刻是诊断窗口
> 伸展、换姿等释放瞬间暴露真实状态。若释放瞬间仍维持收拢/屏障 → 闭合不是瞬时舒适，而是持续自我管制。权重高于静态观察。

## 5. 组合解读规则

1. 朝向直接 + 目光多 + 距离近 → 强趋近（积极）。
2. 朝向不直接 + 屏障 + 零目光 → 排斥/防御组合。
3. 朝向直接 + 目光少 → 警觉或地位尊重，不一定积极。
4. 全部指标零变化 → 无信息，别过度解读。
