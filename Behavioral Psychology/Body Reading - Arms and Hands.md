# Body Reading - Arms and Hands

> [!abstract] 概述
> 手臂开放度、屏障、叉腰、屈伸的直接解读。
> 手臂是中继信号密度最高的部位，也是最依赖站/坐语境的部位（见 [[Body Reading - Standing versus Sitting]]）。

## 1. 开放度 → 态度与地位（站/坐翻转）

| 观察 | 直接解读 | 来源 |
|---|---|---|
| 坐姿收臂（交叉、抱臂） | 拘礼、紧张、自我管制；女性对高地位对象更收拢 | Mehrabian & Friar 1969 |
| 坐姿开放（双手不接触、臂不交叉） | 放松；女编码者此位传达更积极态度（对象年长或年幼时） | Mehrabian 1968a/1968b |
| 站姿收臂 | 可能只是放松；双臂下垂反而更正式 | Mehrabian 1969 |
| 站姿叉腰 | 消极态度 + 对方低地位 | Mehrabian 1968a |

## 2. 抱臂的解码共识

收臂形象被观察者解码为：冷淡、拒斥、羞怯、被动（Machotka 1965）。
中等开放形象最有吸引力；过度张开与完全收拢都不利。

> [!warning] 抱臂的非人际解释清单
> 1. 环境冷。2. 无处放手的习惯位。3. 自我安抚（紧张时的自我接触）。
> 排除顺序：先查温度与习惯基线，再读人际含义。

## 3. 屏障行为（方向性遮挡）

手臂垫在躯干与特定人之间 = 物理屏障 = 缩减对该侧的可及性。

判读三要素：
1. **方向性**：屏障只对着你 → 人际信号；对两侧都一样 → 习惯或环境。
2. **持续性**：伸展、换姿时仍维持 → 刻意管制，权重高。
3. **强度**：轻度遮挡（如撑头顺势挡）与完全屏障（抱臂 + 转身）含义强度不同。

| 观察 | 直接解读 |
|---|---|
| 撑头 + 前臂顺势挡向一侧 | 低唤醒 + 轻度防御的混合；需查方向性 |
| 双臂交叉 + 躯干转向另一侧 | 明确回避/排斥组合 |
| 屏障随对方靠近而加固 | 侵入防御（领地反应） |

## 4. 手臂屈伸 → 趋避动机（效应作用于自己）

| 动作 | 效应 | 来源 |
|---|---|---|
| 屈臂（拉近自己） | 对同时呈现的刺激评价更积极 | Cacioppo 系（运动过程假说） |
| 伸臂（推离） | 评价更消极 | 同上 |

注意方向：这是姿态改变评价（具身效应），不是从姿态读情绪。

## 5. 手部动作 → 情绪聚类

| 观察 | 直接解读 | 来源 |
|---|---|---|
| 对称性上下挥臂 | 欣喜若狂、骄傲 | Dael 聚类 8 |
| 触摸/操控物件 + 头部正直朝向对方 | 愉悦 | Dael 聚类 11 |
| 双手插兜 | 悲伤、宽慰 | Dael 聚类 10 |
| 重复性自我触碰（摸脸、捻指） | 低唤醒/被动情绪的调节动作，无情绪特异性 | Dael 聚类 5/7 |
| 手臂回缩 | 防御成分之一 | Dael 因子 |
| 手臂 + 腿部布置不对称 | 放松的指标 | Mehrabian 因素分析 |

## 6. 实操顺序

1. 确认站/坐语境。
2. 排除非人际解释（温度、习惯、支撑需求）。
3. 查方向性与持续性。
4. 与目光、朝向组合成证据链，再下结论。
