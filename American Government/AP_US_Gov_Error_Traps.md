# AP U.S. Government and Politics — Exam Traps Index

> [!abstract] 概述
> 全 5 单元高频易错点的横向索引。四色分工：**概念辨析**（A 章）、**案例/文献配对**（B 章）、**清单与编号**（C 章）、**FRQ 策略**（D 章）。与 [[AP_US_Government_Main_MOC]] 及各单元 MOC 互链。打印版：`~/高二/美国政治/AP_USGov_Concept_Checklist.pdf`。

## D 章：FRQ 策略与陷阱

### D1 FRQ 命令动词（CED 官方 7 个 Task Verbs）

| 动词 | CED 官方要求 |
|---|---|
| Compare | similarities **and/or** differences |
| Define | 给出词或概念的具体含义 |
| Describe | 给出指定主题的相关特征 |
| Develop an argument | 提出主张并用证据支持 |
| Draw a conclusion | 用现有信息形成有证据支持的准确陈述 |
| Explain | 说明 how 或 why；how 偏关系分析，why 偏动因分析 |
| Identify | 指出信息，不作展开或解释 |

> [!warning] 三个高频误用
> 1. **Compare 不要求同与异都写**——CED 原文是 "similarities **and/or** differences"。
> 2. **Define $\neq$ Describe**：Define 给含义，Describe 给特征。
> 3. **"Develop an argument" 是 FRQ 4 的官方动词**，许多资料漏收；它要求 claim $+$ evidence。

### D2 Argument Essay（FRQ 4）结构

| 组件 | 要求 | 常见丢分 |
|---|---|---|
| Thesis | 可辩驳立场 + 推理线 + 使用课程概念 | 复述 prompt；无立场 |
| Evidence | 2+ 条具体证据（文献/案例/实例） | 泛泛而论；不点名 |
| Reasoning | 解释**为何**证据支持主张 | 只陈述不解释 |
| Opposing view | 正确描述对立观点 + 反驳/让步 | 忽略或误述对立面 |

### D3 SCOTUS Comparison（FRQ 3）结构

| 组件 | 要求 |
|---|---|
| Facts / Issue | 题干指定**必考**案例的事实与争点（非必考案例的事实由题干提供） |
| Holding | 两案的判决 |
| Reasoning | 两案的推理逻辑 |
| Connection | 联系课程概念（原则/制度） |

> [!warning] FRQ 3 铁律
> 题干会**提供非必考案例的摘要**（含事实、争点、判决、推理）。你要写的是：①题干指定**必考案例**的 facts / issue / holding / reasoning；②两者的比较。**从 14 个必考案例中选取匹配的那一个。**

### D4 常见 FRQ 失分点

| 失分 | 原因 | 修复 |
|---|---|---|
| 论点无证据 | 只说"宪法确立了分权"而不引用具体条款 | 引用 Federalist 51 或宪法条文 |
| 证据不具体 | "最高法院有很多重要案例" | 点名 Marbury v. Madison + 具体判决 |
| 混淆 civil liberties 与 civil rights | 将"不受政府干涉"与"政府保护平等"混用 | 明确区分消极自由 vs. 积极权利 |
| 混淆联邦派与反联邦派立场 | 张冠李戴 | 联邦派 = 强中央；反联邦派 = 权利法案 |
| 混淆司法能动与司法克制 | 搞反定义 | 能动 = 积极解释；克制 = 尊重民选部门 |
