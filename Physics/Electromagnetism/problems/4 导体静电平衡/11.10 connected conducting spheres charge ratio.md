# 11.10 connected conducting spheres charge ratio

> [!abstract] 概述
> 本笔记积累1道「导线连接两导体球 + claim-reason 选项」题：半径 $R$ 的球 A 带电 $+Q$、半径 $R/2$ 的球 B 中性，用导线连接后达到静电平衡。关键结论——两球**等势而非等场**：$V_A=V_B$ 给出 $Q_A/Q_B = R_A/R_B = 2$，电荷守恒给出 $Q_A = \dfrac{2Q}{3}$、$Q_B = \dfrac{Q}{3}$；但表面场强 $E = kQ/R^2$，小球场强反而是大球的 2 倍。错选 C 的根因是把「等势」误述为「等场」。

## 1. 导线连接两导体球的电荷分配

> [!question] 题目（AP Physics C: E&M · 截图 51.png）
> Two conducting spheres are isolated from their surroundings. The radii of spheres A and B are R and R/2, respectively. Initially sphere A has charge +Q, and sphere B is neutral. A wire is connected between the sphere. Which of the following gives the final charge on each sphere after equilibrium is reached and provides a statement of reasoning to support this claim?
>
> - A. $Q_A = Q$, $Q_B = 0$, because both spheres must create the same electric field at their surface.
> - B. $Q_A = \dfrac{Q}{2}$, $Q_B = \dfrac{Q}{2}$, because both spheres must create the same electric field at their surface.
> - C. $Q_A = \dfrac{2Q}{3}$, $Q_B = \dfrac{Q}{3}$, because both spheres must create the same electric field at their surface.
> - D. $Q_A = \dfrac{Q}{2}$, $Q_B = \dfrac{Q}{2}$, because both spheres must be at the same electric potential.
> - E. $Q_A = \dfrac{2Q}{3}$, $Q_B = \dfrac{Q}{3}$, because both spheres must be at the same electric potential.

![[1110_connected_spheres_charge_ratio.png]]

> [!info] 图注
> TikZ 重绘（示意，不按比例）。Figure 1：连接前——A 半径 $R$、带电 $+Q$；B 半径 $R/2$、中性。Figure 2：用导线连接后达到静电平衡，电荷重新分配，两球成为单一等势导体。

> [!info] 我的答案: C — 错误 | 正确答案: **E**
> 数值 $Q_A = \dfrac{2Q}{3}$、$Q_B = \dfrac{Q}{3}$ 碰巧正确（等势分配的结果），但理由写成了「same electric field」——等势 ≠ 等场。claim-reason 题要求结论与理由同时正确，故 C 错、E 对。

### 解答

1. **导线连接 ⇒ 单一导体 ⇒ 等势**：导线把 A、B 连成同一导体。静电平衡要求整个导体为等势体：
   $$V_A = V_B$$
   电荷经导线自由移动，直到两球电势相等为止。
2. **孤立球导体的电势**：标准处理取导线足够长、两球各自的电荷分布近似均匀（孤立球），取 $V(\infty)=0$：
   $$V = \frac{1}{4\pi\varepsilon_0}\frac{Q}{R}$$
   代入 $V_A = V_B$：
   $$\frac{k Q_A}{R} = \frac{k Q_B}{R/2} \;\Rightarrow\; Q_A = 2 Q_B$$
   即**等势要求电荷量正比于半径**：$Q \propto R$。
3. **电荷守恒**：连接只重新分配电荷，系统总电荷不变：
   $$Q_A + Q_B = Q$$
   联立得
   $$Q_B = \frac{Q}{3}, \qquad Q_A = \frac{2Q}{3}$$
4. **检验「same electric field」为何错误**：导体表面紧邻场强 $E = \sigma/\varepsilon_0 = kQ/R^2$：
   $$E_A = \frac{k(2Q/3)}{R^2} = \frac{2kQ}{3R^2}, \qquad E_B = \frac{k(Q/3)}{(R/2)^2} = \frac{4kQ}{3R^2} = 2E_A$$
   小球 B 的表面场强是大球 A 的 **2 倍**，两球场强不相等。故「same electric field at their surface」是假命题。
5. **数值自洽检验**：
   - 电势相等：$V_A = k(2Q/3)/R = 2kQ/(3R)$，$V_B = k(Q/3)/(R/2) = 2kQ/(3R)$ ✓ 一致。
   - 电荷守恒：$2Q/3 + Q/3 = Q$ ✓。
   - 反证选项 C 的自洽性：若真按「场强相等」推理，$kQ_A/R^2 = kQ_B/(R/2)^2 \Rightarrow Q_A = 4Q_B \Rightarrow Q_A = 4Q/5$、$Q_B = Q/5$——与 C 所给数值 $2Q/3$、$Q/3$ 矛盾。C 的数值来自等势、理由却写等场，自相矛盾。
   - 选项 D 同病：$Q_A = Q_B = Q/2$ 时 $V_A = kQ/(2R)$、$V_B = kQ/R$，电势不等，与自身理由矛盾。
6. **物理图像**：连接瞬间 $V_A = kQ/R > V_B = 0$，正电荷从高电势的 A 经导线流向低电势的 B（实际移动的是 B→A 的电子），直到两球等势。B 半径小，只需较少电荷就能达到相同电势，故 B 只分到 $Q/3$。

> [!warning] 「等势 ≠ 等场」——导线连接平衡后等的是电势，不是表面场强
> 规则：导体经导线连接成同一导体后静电平衡，整导体等势（$V_A=V_B$）；表面场强 $E=kQ/R^2$ 与曲率有关，半径不同则场强必然不同。半径比 $2:1$ 时场强比为 $1:2$（小球场强大）。
> 防法：看到「导线连接 / 接触」先写两式——$V_1=V_2$ 与 $Q_1+Q_2=Q_{\text{总}}$；用 $V=kQ/R$ 得 $Q\propto R$。问场强时才用 $E=kQ/R^2$，注意是 $R^2$ 不是 $R$。

> [!warning] claim-reason 题：理由错则选项错（即使数值碰巧对）
> 规则：AP 的 claim-reason 选择题要求「结论」与「理由」同时正确。C 的数值恰是正确答案，但理由「same electric field」错误 ⇒ C 错、E 对。
> 防法：把结论与理由拆开各自验证——用理由独立推出数值，若推不出选项所给数值，该选项自相矛盾，直接排除。
